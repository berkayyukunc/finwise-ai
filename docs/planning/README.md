# Planlama Arşivi (Tarihsel)

Bu klasördeki dokümanlar projenin **tasarım aşamasında** yazılmış şartname ve iş planlarıdır. Hedeflenen daha geniş
bir ürünü (mobil uygulama, API katmanı, OCR, LLM tabanlı asistan vb.) tarif ederler ve **mevcut kodu anlatmazlar**.
İçlerindeki performans rakamları ve özellik listeleri ölçülmüş sonuç değil, tasarım hedefidir.
